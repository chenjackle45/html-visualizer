01 · 起手範例

先挑一份真的範例起手

這四份都是完整、能直接打開的頁面，各自內建該情境需要的互動。依你要做的事選一份；拍板題數是第一個分岔，有沒有拍板題、幾題，決定該用哪一份。

編輯風報告

何時用報告、盤點、健檢結論、研究結果。主體是報告、順帶 1–4 題拍板時照原樣用；沒有拍板題，照它的 README 把拍板相關的四樣一起刪。

特徵結論數字 hero、頂端固定章節列、淡色大章節號開場、主張引言帶。

解釋型

何時用教學、概念解釋、機制說明，沒有待拍板。報告類的內容順序（骨架 B）也在這份的 README。

特徵骨架 A 七段：一句話 → 類比 → 核心模型 → 走一遍 → 誤解 → 邊界 → 收合深入。

02 · 色彩與墨色

品牌色拿來填色，小字改用墨色

赤陶、橄欖這些品牌色在米白底上不夠深，當小字會看不清。規則只有一條：24px 以下的字一律用加深過的墨色，品牌色留給色塊、邊線、圖示和大字。

03 · 字體層級

標題用襯線，內文用無襯線

襯線字只給標題和大數字，讀起來像一份刊物；內文、表格、按鈕都用系統無襯線字，掃讀比較快。中文襯線要在字族裡點名（Songti TC、Noto Serif TC），不然換一台電腦標題字體就變了。下面的示例句借用虛構的咖啡豆訂閱服務 Brewly。

頁面大標serif · 500 · 36–60px
下一杯，留給新的豆香
章節標題serif · 500 · 26–34px
讓方案跟著生活調整
小節標題serif · 500 · 21px
每月一份咖啡提案
內文sans · 16px · 行高 1.75 · 最寬 72ch
內文一行最多 72 個字寬。容器可以滿版，色塊和邊框照樣撐開，但裡面的文字要限行長，眼睛換行時才找得到下一行的開頭。
小字sans · 13px · --text-soft

01 · Eyebrow 標籤
3.1

強調詞：換字重，不用斜體

漢字沒有斜體的傳統，瀏覽器硬斜會很難看。預設用「加粗＋深赤陶」，語氣安靜；要更重時用螢光筆底線，一頁最多一兩次。強調詞兩側不加半形空格。

預設：換字重

配送間隔改成六週一次

加重：螢光筆

配送間隔改成六週一次
3.2

中文標題不從詞中間斷開

把標題的語意片段各用 <span class="ph"> 包起來，窄螢幕只會在片段之間換行。下面虛線框就是兩個片段：

04 · 章節編號

編號只有兩種：章節與小節

同一頁混用圈字、裸數字、大浮水印，讀者分不出哪個是大段、哪個是小段。現在全部收斂成兩種，這頁本身就是照這兩種排的。

章節：mono 小字 eyebrow＋襯線標題

02 · 色彩與墨色
品牌色拿來填色

eyebrow 前面一條 24px 赤陶短線。報告類可以另加淡色大浮水印數字，但那時 eyebrow 就不再寫數字，兩者只留一個。

小節：小方框編號＋小標題

2.1底色與填色

方框用墨色字、淡赤陶底、淺赤陶邊。不再用 ①②③ 圈字，也不再用沒有框的赤陶數字。

05 · 卡片與提示框

一個層級最多一層框

章節外面不加卡框，用留白分段；卡片裡要再分區時改用底色，不再套一張白卡。框越少，讀者越容易看出哪些內容屬於同一層。

5.1

卡片

讓方案跟著生活調整

想換季節豆款、拉長配送間隔，或暫停一期，都在同一張方案卡裡改。

月費 NT$ 690 · 每月一份咖啡提案。卡內的子區塊用淺灰底，不再套白卡框。

白底、1.5px 暖灰邊、14px 圓角；卡片內文同樣限 72ch。

5.2

提示框

提示想先試喝再決定？第一期可以只選半磅。
注意暫停要在下一期出貨前五天設定，晚了這一期照常寄出。

外框滿版，裡面的文字限行長；注意框的邊線用金黃，標題字用加深的黃色墨色。

5.3

狀態標籤

已出貨 待確認 本月新豆 季節限定

標籤、計數、時間膠囊一律不換行，手機上才不會斷成「待確／認」。

5.4

收合區塊

細節收進可展開的區塊，主線讀起來不被打斷。摘要寫成一句問題，讀者看一眼就知道裡面在講什麼；列印時自動展開。

這份樣張的色彩與文字怎麼分工？

米白底留出閱讀空間，赤陶標示入口與重點。襯線標題放慢閱讀節奏，強調詞換字重、不用斜體；內文用清楚的無襯線字體。

Brewly 是虛構的咖啡豆訂閱服務，公司、情境與 NT$ 690 月費皆為虛構。這頁展示的是視覺風格，不是可下單的商業網站。

5.5

回傳列

每頁底部固定一條回傳列，讀者不用找就知道怎麼回饋：左邊告訴他「反白文字就能留言」和已留幾則，右邊一鍵把留言整理好複製給 AI。沒有拍板題的頁複製「頁面標題＋全部留言」；有拍板題的頁換成拍板摘要與進度。
